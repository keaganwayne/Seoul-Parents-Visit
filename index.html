How to use this guide

  1. Start with Seoul Map to understand Seoul by neighbourhood.
  2. Click a district on the map to see sights, food, and cafés.
  3. Click any place name to drop an approximate pin on the map.
  4. Use the Google Maps button on each card for exact directions or taxi navigation.
  5. Use Hotel Shortlist if accommodation is still undecided.
  6. Use Suggested Itinerary for day-course ideas with warnings and meal stops.

Design logic

This guide is built for English-first use. Korean names remain visible for taxis, Naver/Kakao searches, and showing drivers or hotel staff.

Suggested routes combine Local personal recommendations with practical sequencing, warnings, and meal stops.
